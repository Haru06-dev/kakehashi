Vocabulary Words

Import JLPT vocab (open dataset, ~8,100 words total)

Needs internet. Source traces back to tanos.co.uk (Jonathan Waller), MIT-licensed redistribution. Skips words you've already added.

Already have words without pitch accent?

Fills pitch accent for any word in your list that's missing it, using Kanjium. Words it can't find get tagged "needs-pitch" so you can filter to them in the Vocab tab and add pitch manually (e.g. via OJAD or Weblio).

Kanji

Import JLPT kanji (open dataset, 2,211 kanji total)

Needs internet, first import downloads ~5.5MB (cached after). Source: KANJIDIC + JLPT levels from tanos.co.uk, MIT-licensed. Skips kanji you've already added.

Already have kanji missing readings/meaning?

Fills onyomi, kunyomi, and meaning for any kanji in your list missing them, using the same dataset the JLPT import uses. Anything not found there is left as-is for manual entry.
